## 1. Show that $\alpha + \beta = \beta + \alpha$ for all $\alpha, \beta \in \mathbb{C}$

Let  
$\alpha = a + bi$  
$\beta = c + di$  
where $a, b, c, d \in \mathbb{R}$

\[
\alpha + \beta = (a + c) + (b + d)i
\]
\[
\beta + \alpha = (c + a) + (d + b)i
\]

Since addition in $\mathbb{R}$ is commutative:

\[
\alpha + \beta = \beta + \alpha \quad \checkmark
\]

---

## 2. Show that $\lambda(\alpha + \beta) = \lambda \alpha + \lambda \beta$ for $\lambda \in \mathbb{R}$ and $\alpha, \beta \in \mathbb{C}$

Let  
$\alpha = a + bi$  
$\beta = c + di$  
where $a, b, c, d \in \mathbb{R}$

\[
\alpha + \beta = (a + c) + (b + d)i
\]
\[
\lambda(\alpha + \beta) = \lambda(a + c) + \lambda(b + d)i = (\lambda a + \lambda c) + (\lambda b + \lambda d)i = \lambda \alpha + \lambda \beta \quad \checkmark
\]

---

## 3. Show that $\alpha(\lambda \beta) = \lambda(\alpha \beta)$

Let  
$\alpha = a + bi$  
$\beta = c + di$  
where $a, b, c, d \in \mathbb{R}$

### Compute $\alpha \beta$:
\[
\alpha \beta = (a + bi)(c + di) = ac + adi + bci + bdi^2 = (ac - bd) + (ad + bc)i
\]

### Compute $\lambda(\alpha \beta)$:
\[
\lambda(\alpha \beta) = \lambda(ac - bd) + \lambda(ad + bc)i
\]

### Compute $\lambda \beta$:
\[
\lambda \beta = \lambda(c + di) = \lambda c + \lambda di
\]

### Compute $\alpha (\lambda \beta)$:
\[
\alpha(\lambda \beta) = (a + bi)(\lambda c + \lambda di) = a \lambda c + a \lambda di + b i \lambda c + b i \lambda di
\]
\[
= \lambda(ac - bd) + \lambda(ad + bc)i
\]

Thus:

\[
\alpha(\lambda \beta) = \lambda(\alpha \beta) \quad \checkmark
\]

## 4. Restating distributivity

Let  
$\alpha = a + bi$  
$\beta = c + di$

\[
\lambda(\alpha + \beta) = \lambda((a + c) + (b + d)i) = \lambda a + \lambda c + (\lambda b + \lambda d)i = \lambda \alpha + \lambda \beta \quad \checkmark
\]

## 5. Show that for all $\alpha \in \mathbb{C}$, there exists a unique $\beta \in \mathbb{C}$ such that $\alpha + \beta = 0$

Let $\alpha = a + bi$

Define $\beta = -\alpha = -a - bi$  
Then:

\[
\alpha + \beta = (a + bi) + (-a - bi) = 0
\]

Thus, such $\beta$ exists.

### Uniqueness:

Suppose $\gamma$ also satisfies $\alpha + \gamma = 0$.  
Then $\gamma = -\alpha = \beta$ by the **definition of additive inverse**, which is **unique**.

\checkmark
\]

## 6. Show that for $\alpha \in \mathbb{C}$, $\alpha \neq 0$, there exists a unique $\beta \in \mathbb{C}$ such that $\alpha \beta = 1$

Let $\alpha = a + bi$, with $a, b \in \mathbb{R}$ and $\alpha \neq 0$.

By **definition**, $\frac{1}{\alpha}$ denotes the **unique** multiplicative inverse of $\alpha$, meaning:

\[
\alpha \left( \frac{1}{\alpha} \right) = 1
\]

### Explicit expression:

\[
\frac{1}{a + bi} = \frac{a - bi}{a^2 + b^2} = \frac{a}{a^2 + b^2} - \frac{b}{a^2 + b^2}i
\]

Thus, $\beta$ exists and is **unique**.

\checkmark
